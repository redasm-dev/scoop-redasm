# REDasm Scoop Bucket

Official Scoop bucket for [REDasm](https://redasm.dev) - The Open Source Disassembler.

## Install

```powershell
scoop bucket add redasm https://github.com/redasm-dev/scoop-redasm
scoop install redasm
```

## Requirements

- [Scoop](https://scoop.sh)
- Git (`scoop install git`)
